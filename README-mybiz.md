# BizManager

A simple, beginner-friendly small business management website built with **HTML, CSS, and JavaScript** in a single `index.html` file.

## Features

- Welcome page with a Start button
- Dashboard with business summary cards
- Inventory and product management
- Sales and billing interface
- Privacy Policy and Terms & Conditions pages
- Responsive layout for mobile and desktop
- Subtle text animations
- Browser-based storage using `localStorage`
- No API key or installation required

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Start using BizManager.

## Publish with GitHub Pages

1. Upload `index.html` and `README.md` to the root of your GitHub repository.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder, then save.
5. Wait for GitHub Pages to publish your site. The published URL will appear in the Pages settings.

## Data and privacy

BizManager stores its records in the browser's local storage on the device and browser you use. Data is not automatically synced to other devices and may be lost if browser data is cleared. This single-file version does not use a server or shared database. Avoid entering sensitive or confidential information.
